# CTF Writeups

This repository contains writeups and solving scripts for various CTF challenges.

Each challenge folder typically follows this structure:

- A solving script (for example, an exploit or Python script) to solve the challenge
- A writeup explaining the approach, reasoning, and solution
- An images folder when the writeup includes screenshots or diagrams

Example layout:

- ChallengeName/
  - solve.py or challengeName.py (sometimes other kind of languages used)
  - writeup_ChallengeName.md
  - images/ (optional)

This makes it easy to review both the practical solution and the explanation of how the challenge was solved.
